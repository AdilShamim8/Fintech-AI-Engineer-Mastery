# Notes — Your Knowledge Base

> Templates live in `templates/`. Copy them; don't edit the templates. Notes are committed — they are the durable half of the curriculum (the buildable half is in `projects/`).

## Layout

```text
notes/
├── concepts/        one file per concept, written from memory, math included
├── experiments/     hypothesis → setup → result → surprise
├── case-notes/      case-study answers written BEFORE reading the commentary
├── decisions/       ADR-style records of design choices in your projects
├── artifacts/       recorded oral exams, checkpoint presentations, demo videos
└── reviews/         weekly, monthly, quarterly reviews
```

## The Rules (from LEARNING.md)

1. A concept note exists only after you can write it with the source closed.
2. Every experiment note names one surprise.
3. Case notes are timestamped before reading solutions.
4. Reviews are honest: scope slips are recorded, not laundered.
