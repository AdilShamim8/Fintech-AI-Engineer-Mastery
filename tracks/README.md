## How To Use Tracks

1. **Depth check:** after finishing a phase, walk the track row for that topic — did you reach the track's level, or only the phase's exercise?
2. **Gap recovery:** if a later phase exposes a weakness, jump to the specific track row (not the whole track) and rebuild.
3. **Path customization:** for interviews in a specific domain (e.g., fraud), the relevant track is your revision spine.
4. **Portfolio assembly:** the tracks' evidence bars are exactly the portfolio artifacts hiring managers want to see.

## Reading Order Note

Tracks assume the AI engineering baseline and skip generic content by design. If a track row feels mysterious, the linked phase is the prerequisite — tracks point back, phases point forward.
